# ⚙️ Estructuras de Datos y Algoritmos II (EDA II) - Prácticas

![Status](https://img.shields.io/badge/Status-En%20Desarrollo-blue)
![C++](https://img.shields.io/badge/Code-C%2B%2B-blue)
Repositorio de estudio y práctica autodidacta centrado en Estructuras de Datos y Algoritmos II. Contiene implementaciones de estructuras complejas, resolución de problemas y optimización de algoritmos.

## 📌 Temas de Estudio

El repositorio está organizado según los temas clásicos de EDA II:

| Categoría | Temas Específicos |
| :--- | :--- |
| **Árboles** | AVL, Rojo-Negro, B-Trees, Tries |
| **Grafos** | Representación, Recorridos (BFS, DFS) |
| **Alg. en Grafos** | Dijkstra, Kruskal, Prim, Floyd-Warshall |
| **Tablas Hash** | Funciones Hash, Manejo de Colisiones |
| **Algoritmos Avanzados** | Programación Dinámica, Backtracking |
